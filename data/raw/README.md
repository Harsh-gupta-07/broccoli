# Raw data (not committed)

Download the **M5 Forecasting – Accuracy** data from Kaggle and place these three files here:

- `sales_train_evaluation.csv`
- `calendar.csv`
- `sell_prices.csv`

```bash
kaggle competitions download -c m5-forecasting-accuracy
unzip m5-forecasting-accuracy.zip calendar.csv sales_train_evaluation.csv sell_prices.csv -d data/raw/
```

You must accept the competition rules on Kaggle first.
